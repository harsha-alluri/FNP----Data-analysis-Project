Ferns & Petals Sales Analysis Dashboard
📌 Project Overview

This project is an interactive sales analysis dashboard built using Microsoft Excel.
The dashboard analyzes sales data from Ferns & Petals (FNP) to uncover valuable business insights related to revenue, customer behavior, product performance, and delivery trends.

Business Problems Solved

The dashboard answers the following business questions:

1.Total Revenue Analysis
2.Average Order & Delivery Time
3.Monthly Sales Performance
4.Top Products by Revenue
5.Average Customer Spending
6.Sales Performance of Top Products
7.Top 10 Cities by Orders
8.Order Quantity vs Delivery Time Analysis
9.Occasion-wise Revenue Comparison
10.Product Popularity by Occasion

**Dashboard Features**

Interactive Slicers
KPI Summary Cards
Revenue Analysis Charts
Monthly Trend Visualization
Product Performance Tracking
City-wise Order Analysis
Occasion-based Insights

**Tools Used**

Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Conditional Formatting

**Key Insights**

Anniversary and Raksha Bandhan generated high revenue.
Colors and Soft Toys were among the top-performing categories.
Certain cities contributed significantly to total orders.
Revenue showed strong spikes during festive seasons.
